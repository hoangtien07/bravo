# Google Stitch screen prompts - Bravo Agent AI

Use these sequentially after loading the root `DESIGN.md` and official logo assets.

## 1. Design Foundation

```text
Create a Design Foundation page for Bravo Agent AI, a Vietnamese enterprise ERP advisory product.
Show approved color tokens, typography, spacing, responsive grid, logo safe area, paired 29-degree
// motif, icon style, controls, navigation, evidence labels, tables, drawers, dialogs, empty states,
skeletons, and keyboard focus states.

Include: Not assessed, Missing evidence, In progress, Ready, Conflict, Not applicable, Draft,
Approved, Executed, and Verified. Keep them semantically distinct. Do not create app screens yet.
```

## 2. Sign in and Application Shell

```text
Design the Bravo Agent AI sign-in screen and authenticated shell at 1440px and 1024px.
Use a restrained two-column sign-in: official BRAVO logo and one meaningful // moment on the left,
compact authentication panel on the right. SSO is primary when enabled. No stock or AI imagery.

The 264px collapsible sidebar contains New conversation, Financial Close, Conversations, Knowledge,
Approvals, and role-gated Administration. User/environment sits at the bottom. The context header
shows task, company, branch, period, BRAVO version, evidence status, Share, and More.
```

## 3. New Conversation

```text
Design the new-conversation screen for Bravo Agent AI. Its single job is to start a useful BRAVO
task. Show a role-aware Vietnamese greeting, prominent composer, Auto profile, attachments, a
draft-only/evidence policy, four realistic Financial Close starters, and recent conversations below.

Avoid a marketing hero, fake metrics, oversized gradients, and generic feature-card grids. Create
1440px, 1024px, 390px, empty, attachment-uploading, offline, and permission-limited states.
```

## 4. Active Conversation and Evidence Drawer

```text
Design an active Vietnamese advisory conversation for Bravo Agent AI. Use left navigation/history,
a readable center column, and an optional 380px evidence drawer. The answer naturally presents the
understood outcome, prerequisites, next action, uncertainty, and one targeted clarification. Do not
expose chain-of-thought.

Inline citations focus matching sources. Show source, page/cell or data scope, company, period,
environment, BRAVO version, approval status, and whether each fact is supplied, verified, inferred,
conflicting, or missing. Create streaming, complete, stale, conflict, unavailable-source, and mobile
states without layout shifts.
```

## 5. Financial Close Readiness

```text
Design the Financial Close Readiness workspace. Use a governed Evidence Rail built from the BRAVO
paired // motif. Show: scope/period, source documents posted, subledgers reconciled, applicable
period processes, period-end entries, closing controls, mappings/opening balances, and variance
review.

Each item is Not assessed, Missing evidence, In progress, Ready, Conflict, or Not applicable.
Selection opens reason, condition, evidence, responsible role, and next action. Do not use an
unexplained percentage, donut, or speedometer. Include desktop, compact, mobile summary, empty,
conflict, and limited-access states.
```

## 6. Financial Close Evidence Graph

```text
Create a desktop-first Financial Close Evidence Graph for Bravo Agent AI. This is a governed,
stable, left-to-right dependency map, not a force-directed knowledge graph. Connect reporting
outcome to accounting prerequisites, BRAVO controls, and supporting evidence.

Use official green/orange and paired 29-degree // directional markers. Node selection opens a right
inspector with reason, evidence, data scope, BRAVO version, company, period, status, and responsible
role. Include milestone/status/evidence/period/role filters, search, zoom, fit, reset, and accessible
hierarchical list view.

Show neutral permission boundaries without hidden labels, counts, or edges. Do not invent values,
table names, menu names, or verified claims. No glowing nodes, particles, or AI-brain imagery.
```

## 7. Draft and Approval Review

```text
Design the Bravo Agent AI Draft and Approval Review workspace. Show proposed change, purpose,
affected scope, before/after, evidence, deterministic validation, risk, missing checks, requester,
reviewer, timestamps, and audit trail. Actions: Approve, Request changes, Reject.

Draft, Approved, Executed, and Verified must remain distinct. Create queue, detail, request-changes,
rejection, empty, validation-failed, permission-denied, and mobile states.
```

## 8. Knowledge Library

```text
Design the governed Knowledge Library. Show owner, source type, BRAVO version, effective date,
approval, visibility scope, ingestion status, page/cell traceability, supersession, and conflicts.
Include readable search and filters.

Create list, detail, upload/review, ingestion-progress, ingestion-failed, superseded, conflicting,
empty, and permission-limited states. Do not use citation volume as a quality score.
```

## 9. Administration and Audit

```text
Design a role-gated Administration and Audit workspace. Include identity/authorization scope,
environment policy, runtime policy, controlled cloud egress, corpus governance, audit events,
failed safety checks, and service health. Explain security state without exposing credentials,
secret values, hidden users, or tenant metadata.

Create overview, audit detail, degraded service, blocked egress, policy conflict,
permission-denied, and mobile read-only states.
```

## 10. Consistency and responsive audit

```text
Audit all Bravo Agent AI frames as one product. Normalize typography, spacing, colors, radii,
component states, navigation, and Vietnamese action vocabulary.

Verify 1440px, 1024px, and 390px; WCAG 2.2 AA; visible keyboard focus; 44px mobile targets; correct
drawer/dialog focus; reduced motion; and an accessible graph list. Remove generic AI decoration,
fake values, unsupported exact claims, and ambiguity among Draft, Approved, Executed, and Verified.
```
